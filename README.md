# 🚀 Data + AI Engineering — 88-Day Learning Journey

A hands-on journey from **Data Engineering → Data + AI Engineering**, built around one principle:

> **Learn the concept → Experiment → Build → Test → Debug → Explain → Move Forward**

The roadmap progresses from LLM fundamentals to document AI, semantic search, RAG, evaluation, agents, MCP, security, and finally production AI engineering.
